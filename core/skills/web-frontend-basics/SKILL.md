# Web frontend basics

- Semantic HTML, one `<h1>`, landmarks, alt text, labels; keyboard reachable; contrast >= 4.5:1.
- Mobile-first responsive CSS (flex/grid, `clamp()`); no horizontal scroll.
- Minimal JS; no framework unless needed. Defer scripts; optimise images; set meta viewport/title/description.
- Verify in a browser at 375px and 1280px; run Lighthouse; fix a11y issues.
