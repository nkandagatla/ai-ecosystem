# Changelog

## 2.0.0 - unreleased

### Fixed (layouts verified against the official docs)
- **Codex:**
  - Skills now install to `.agents/skills` (`~/.agents/skills` at user scope), not `.codex/skills`.
  - Agents are now TOML files in `.codex/agents/*.toml` with `developer_instructions`.
  - The deprecated `prompts/` output has been removed; workflows are now skills.
- **Copilot / VS Code:**
  - Prompt files use `agent:` instead of the removed `mode:`.
  - Skills install to `.agents/skills` instead of the `applyTo: "**"` instructions, which loaded every skill into every request.
  - User scope is now supported: `~/.copilot/agents`.
- **Cursor:**
  - Legacy `.cursor/commands` and the duplicate always-on index rule are no longer generated (Cursor reads `AGENTS.md`).
  - Skills install to `.agents/skills`.
  - Agents get `readonly` and `model`.
- **Claude Code:**
  - Workflows are skills (`.claude/skills/<wf>`) instead of legacy commands.
  - Agents declare `skills:` (preload) and `tools` (for read-only agents).
- **Windsurf:**
  - Rules are capped at 12,000 characters and `global_rules.md` at 6,000.
  - Agent roles use `trigger: manual`.
  - Global workflows (unverified location) are no longer written.
- **Interactive prompts:** "Target tools" no longer crashes on names such as `claude,cursor`. Numbers, names, aliases and `all` are all accepted, and invalid input re-prompts.
- **Frontmatter:** replaced the line-split parser with a YAML-subset parser that handles quoted values, colons, block lists, lists of maps and `|` blocks. PyYAML is used if installed.
- **Uninstall:** only directories the installer created are pruned, instead of every empty directory under the root.
- **Manifests:** separate per scope (project `.ai-ecosystem.json`, user `~/.ai-ecosystem/manifest.json`). v1 manifests are migrated automatically.

### Added
- **New targets:** Gemini CLI (`GEMINI.md`, TOML commands, `settings.json` MCP) and Kiro (steering, MCP).
- **MCP servers:** `core/mcp/` (github, playwright, context7, aws-docs, terraform) rendered for each tool; profiles choose which ones to use. Flags `--mcp` and `--no-mcp`.
- **Safety guard hook** for Claude Code (PreToolUse) and Cursor (beforeShellExecution). Disable with `--no-hooks`.
- **Agent metadata:** `readonly`, `model` and `handoffs`, which become Copilot handoff buttons and "Hand off" sections.
- **`validate` command:**
  - Checks skill name/dir/description limits, agent, workflow and profile references, MCP definitions, and external skills.
  - Checks that the plugin is up to date.
  - Runs `claude plugin validate` when available.
- **Claude Code plugin and marketplace** (`plugins/ai-ecosystem`, `.claude-plugin/marketplace.json`) generated by `build-plugin`, with a `--check` mode for CI.
- **Packaging:**
  - pipx/pip (`pyproject.toml`, `ai-ecosystem` console script, data bundled in the wheel).
  - npx (`bin/ai-ecosystem.mjs`).
  - A `get.sh` curl one-liner.
  - A tag-triggered release workflow.
- **ai-cloud-skills pinning:** `vendor.lock` with `sync` / `sync --latest`.
- **Safe merging:** JSON configs are merged key by key, and `update` keeps user-modified files (use `--force` to overwrite).
- **Subcommands:** `install`, `update`, `uninstall`, `validate`, `sync`, `build-plugin`, `list`.
- **Profiles:** `api-backend`, `mobile`, `data-ml`, `k8s-platform`, `aws-iac`, `azure-iac`, `gcp-iac`. Core skills `api-design` and `mobile-app-basics`.
- **Example:** `examples/vibe-web-page` (plan, ADR, page, generated layout).
- **Tests:** a unittest suite covering every profile × target, user scope, merge and uninstall round-trips, update and stale removal, interactive name, number and `all` input, the guard hook and the plugin check. CI runs on Python 3.8 and 3.13.

## 1.0.0
