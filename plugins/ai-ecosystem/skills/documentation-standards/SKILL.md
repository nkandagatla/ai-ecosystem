# Documentation standards

- README order: what it is, quickstart (copy-paste runnable), usage, architecture, configuration, contributing, license.
- Use mermaid for diagrams. Keep examples tested.
- Runbooks: symptom -> diagnosis -> fix -> escalation.
- Changelog follows Keep a Changelog.
