# Requirements discovery

1. Restate the goal in one sentence and list non-goals.
2. Identify users and their top 3 jobs-to-be-done.
3. Write stories: *As a <user> I want <capability> so that <outcome>*.
4. Add acceptance criteria as Given/When/Then; each must be testable.
5. List risks, dependencies and open questions; mark assumptions.
6. Save to `docs/plan.md`.
