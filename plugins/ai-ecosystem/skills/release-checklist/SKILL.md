# Release checklist

- [ ] CI green; review approved; security findings resolved or accepted
- [ ] Version bumped (semver); CHANGELOG updated; release notes drafted
- [ ] Migration/rollback plan written and tested
- [ ] Monitoring and alerts in place; owner on call
- [ ] Human approval recorded before tag/publish/deploy
